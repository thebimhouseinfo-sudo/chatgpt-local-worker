# Software Development SOP

1. Load project context for the confirmed workspace.
2. Inspect before editing: file tree/search, then exact files.
3. Prefer small patches over rewrites.
4. Reuse existing filesystem/shell/git/checkpoint tools; do not create duplicate coding tools in the Job Pack.
5. Run the repository's own validation commands when available.
6. Review the final diff and call out any unverified behavior.
7. Write/retain outputs only at the confirmed destination.
