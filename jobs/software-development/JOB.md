# Software Development

## Goal
Modify a confirmed repository/folder while preserving the existing MCP core workflow and leaving a validated result.

## Completion criteria
- Target workspace is concrete.
- Relevant project instructions/context are loaded.
- Changes are scoped to the requested task.
- Existing build/test/lint commands are used when available.
- Git diff is reviewed before completion when the target is a Git repository.
- Pack validators and task-specific validation pass, or failures are reported explicitly.
