# Technical Review

## Goal
Review confirmed technical material and produce a traceable report without silently changing the source.

## Completion criteria
- Review source and report destination are concrete.
- Review criteria come from the user, the source, or this pack—not from invented assumptions.
- Findings cite the relevant source location where practical.
- Unverifiable items are marked as such.
- Report is written to the confirmed destination.
- Pack validators pass.
