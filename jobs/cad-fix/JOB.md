# CAD Fix

## Goal
Apply controlled CAD/AutoLISP corrections to a confirmed source and produce a validated output.

## Completion criteria
- Source and result destinations are concrete.
- Existing CAD/LISP conventions are inspected before modification.
- Changes do not invent layer/mapping/business rules not present in the task or pack.
- Relevant syntax/static checks are run where available.
- Final changed files are identified.
- Pack validators pass.
