# HVAC Takeoff SOP

1. Inventory the confirmed source folder before extracting values.
2. If a reference/sample folder is provided, treat it as formatting/mapping guidance, not as evidence for project quantities.
3. Read project technical data/drawings/specs required by the requested takeoff.
4. Keep source-to-output traceability for each extracted equipment/material item.
5. Do not infer missing model numbers, capacities, quantities, accessories, or scope inclusions unless the Job Pack is later extended with an explicit rule.
6. Write only to the confirmed result destination.
7. Run the declared validators before reporting completion.

If a business rule is absent from this pack, surface it as unresolved rather than creating a new rule inside the runtime.
