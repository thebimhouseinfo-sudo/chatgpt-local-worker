# Setup guide images

The visual setup guide uses the four screenshots already stored in this folder:

- `1.png` — enable Developer mode in ChatGPT Plugins settings
- `2.png` — open Plugins and start creating a new plugin
- `3.png` — configure `gptworker` and connect it to the Secure MCP Tunnel
- `4.png` — call `@gptworker` for the first time

The guide is `docs/setup-guide/index.html`.

Keep these filenames stable so the setup guide does not need code changes when the screenshots are replaced with newer captures.
