# Setup guide images

Copy the onboarding screenshots into this folder using these exact names:

- `01-developer-mode.png` — how to enable Developer Mode
- `02-create-plugin.png` — how to create the GPTWorker Plugin/App
- `03-select-tunnel.png` — how to choose/paste the Secure MCP Tunnel
- `04-first-use.png` — how to call `@gptworker` and `gptworker/` for the first time

The local guide at `docs/setup-guide/index.html` automatically shows the images when they exist. Missing images fall back to a placeholder, so no HTML changes are required.
