Kết nối GPTWorker với ChatGPT

Hướng dẫn này dành cho người dùng không cần biết lập trình. Hãy làm lần lượt từng bước, bấm đúng tên nút được ghi trên màn hình.

Nếu bạn đang chạy setup-test.bat, hai ô Tunnel ID và API key chỉ là thử giao diện: có thể nhập bất kỳ chữ nào để đi tiếp và dữ liệu đó không được lưu.

A

Tạo Secure MCP Tunnel trên OpenAI

Đây là “đường nối an toàn” để ChatGPT có thể nói chuyện với GPTWorker đang chạy trên máy của bạn. Không cần hiểu kỹ thuật bên trong; chỉ cần làm đúng các bước sau.

  1. Mở OpenAI Platform và vào Organization → Tunnels.
  2. Nếu có phần quyền cho Tunnels, bật Read và Use. Nếu chính bạn là người tạo hoặc sửa Tunnel, bật thêm Manage.
  3. Nhấn tạo Tunnel mới và đặt tên dễ nhớ, ví dụ gptworker.
  4. Nếu có mục chọn ChatGPT workspace, hãy chọn đúng workspace mà bạn sẽ dùng GPTWorker.
  5. Nhấn Create/Save.
  6. Sau khi tạo xong, copy Tunnel ID. Giá trị thật thường bắt đầu bằng tunnel_....
Vì sao cần quyền Use? Read chỉ cho phép xem Tunnel. GPTWorker cần Use để thực sự dùng Tunnel và kết nối với ChatGPT.
B

Tạo API key cho GPTWorker

API key này giống như “chìa khóa” cho phép GPTWorker sử dụng Tunnel vừa tạo.

  1. Mở OpenAI Platform → API Keys.
  2. Nhấn Create new secret key.
  3. Đặt tên dễ nhớ, ví dụ gptworker-runtime.
  4. Tại Permissions, chọn Restricted.
  5. Tìm mục Tunnels và bật đủ cả Read + Use.
  6. Không dùng Read Only, vì như vậy sẽ thiếu quyền Use.
  7. Không cần bật All cho toàn bộ API key; GPTWorker chỉ cần quyền Tunnels phù hợp.
  8. Nhấn tạo key và copy key ngay khi OpenAI hiển thị. Key thật thường bắt đầu bằng sk-....
Quan trọng: nếu chỉ bật Read mà quên Use, Tunnel có thể được nhìn thấy nhưng GPTWorker sẽ không kết nối/chạy đúng.

Cấu hình plugin GPTWorker

Nhập đúng như hình 4:

  • Name: gptworker
  • Description: có thể để trống
  • Connection: chọn Tunnel — không chọn Server URL
  • Available tunnels: chọn đúng Tunnel của GPTWorker từ danh sách
  • Không dùng Use tunnel ID instead
  • Authentication: chọn No Auth
  • Tick ô xác nhận ở cuối, sau đó nhấn Connect/Create
Quan trọng: không nhập URL MCP local và không paste Tunnel ID vào ô URL. Chỉ chọn Tunnel rồi chọn Tunnel có sẵn trong danh sách.

4

Restart Windows và bắt đầu sử dụng

Sau khi plugin đã được tạo thành công, hãy restart Windows. GPTWorker được cài để tự khởi động cùng Windows, vì vậy bước này đồng thời kiểm tra auto-start hoạt động đúng.

Sau khi Windows khởi động lại, mở ChatGPT, vào một chat và gõ:

@gptworker

Chọn GPTWorker khi ChatGPT hiện plugin. Sau khi GPTWorker đã được gọi, gõ tiếp:

gr/help

Hãy đọc hướng dẫn sử dụng trước khi bắt đầu công việc đầu tiên. gptworker/help vẫn được hỗ trợ như alias tương thích. Phần help giải thích Job, Workspace và các lệnh chính của GPTWorker.

Hoàn tất

Từ những lần sau, GPTWorker sẽ tự chạy nền cùng Windows. Bạn chỉ cần mở ChatGPT và gọi @gptworker. Khi cần xem lại cách sử dụng, gõ gr/help (hoặc alias gptworker/help). Có thể tắt hoặc restart GPTWorker thủ công từ icon ở system tray.
