Kết nối GPTWorker với ChatGPT

Tunnel đã chạy. Hãy hoàn tất 3 bước dưới đây trong tab ChatGPT Settings vừa được mở.

Trang này được lưu ngay trong GPTWorker và có thể mở lại bất cứ lúc nào.

1

Bật Developer Mode

Trong ChatGPT, vào Settings → Apps → Advanced Settings → Developer Mode và bật Developer Mode nếu chưa bật.

Ảnh hướng dẫn sẽ hiển thị tại đây khi có file
images/01-developer-mode.png
2

Tạo Plugin/App mới

Mở khu vực tạo Plugin/App mới, đặt tên gptworker, chọn Connection: Tunnel rồi chọn Tunnel vừa tạo hoặc paste Tunnel ID.

  • Name: gptworker
  • Connection: Tunnel
  • Chọn đúng Tunnel của GPTWorker
  • Chạy Scan Tools / Test connection rồi Create/Save
Ảnh hướng dẫn sẽ hiển thị tại đây khi có file
images/02-create-plugin.png
Ảnh hướng dẫn sẽ hiển thị tại đây khi có file
images/03-select-tunnel.png
3

Gọi GPTWorker lần đầu

Mở một chat mới và gọi Plugin/App:

@gptworker

Sau đó thử:

gptworker/

Nếu kết nối đúng, ChatGPT sẽ hiển thị các lệnh chính của GPTWorker.

Ảnh hướng dẫn sẽ hiển thị tại đây khi có file
images/04-first-use.png

Hoàn tất

Từ lần sau chỉ cần chạy run.bat, mở ChatGPT và gọi @gptworker.
